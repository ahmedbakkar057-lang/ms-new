# MS VPS — تشغيل اللوحة وبوت النقاط

## الملفات

- `vps_panel.py`: تطبيق Flask ولوحة إنشاء حسابات المستخدمين.
- `main.py`: بوت تيليجرام الكامل: حسابات بالنقاط، إدارة المستخدمين، الأكواد، الدعم والإعدادات.
- `requirements.txt`: اعتماديات التطبيق والبوت.
- `Dockerfile` و`docker-compose.yml` و`railway.json` و`Procfile`: ملفات التشغيل والنشر.

## طريقة عمل نقاط الحسابات

- السعر الابتدائي: **20 نقطة لكل 10 أيام**؛ المدة يجب أن تكون 10 أيام أو مضاعفاتها. تتغير الأسعار من لوحة البوت الإدارية.
- يختار المستخدم لغة السيرفر واسمه واسم دخول الموقع وكلمة مرور لا تقل عن 12 حرفاً، ثم يُخصم الرصيد مرة واحدة بعد حجز النقاط وإنشاء الحساب. إذا فشل الإنشاء تُعاد النقاط.
- حساب الموقع يُكتب في `users.json` المشتركة مع اللوحة، وتُحفظ كلمة المرور بصيغة hash salted، مع رمز وصول مستقل.
- يحصل المستخدم على النقاط عبر نظام الدعوات/الأكواد أو دفعات Telegram Stars المتاحة في البوت.

## لوحة المالك في البوت

- المعرّف الإداري الوحيد الافتراضي هو `8122328795`؛ لا تُقبل قائمة مشرفين إضافية.
- أرسل `/admin` في محادثة خاصة مع البوت لفتح لوحة الإدارة. أوامر إدارة المستخدمين والرصيد والسيرفرات والأكواد والإذاعة والإعدادات والنسخ الاحتياطية والاشتراك الإجباري والدعم وقفل البوت محمية بمعرّف المالك.
- لوحة الويب تظل مقيدة بإنشاء حسابات المستخدمين فقط؛ تغيير كلمة مرور المالك وبقية صفحات الإدارة محجوبة من الخادم.

## متغيرات التشغيل

اضبط الأسرار في Railway Variables أو ملف `.env` محلي **غير مرفوع إلى Git**:

```env
RUN_BOT=1
TELEGRAM_BOT_TOKEN=<توكن جديد محفوظ كسِر>
TELEGRAM_ADMIN_ID=8122328795
BASE_PATH=/app/panel_data
PANEL_URL=https://your-public-panel-domain
```

**لا تستخدم أي توكن ظهر في ملف أو رسالة سابقة.** ألغِ كل توكن مكشوف عبر BotFather، أنشئ واحداً جديداً، ثم خزّنه في `TELEGRAM_BOT_TOKEN` فقط. لا يوجد توكن افتراضي أو كلمة مرور أدمن للموقع في الكود.

## التشغيل بـ Docker Compose

بعد ضبط المتغيرات أعلاه في البيئة أو في ملف `.env` محلي:

```bash
docker compose up -d --build
```

افتح `http://localhost:20276`. البيانات تحفظ في Volume اسمه `panel_data`.

## التشغيل بـ Docker مباشرة

```bash
docker build -t ms-vps-panel .
docker run -d --name ms-vps-panel \
  -p 20276:20276 \
  -e PORT=20276 \
  -e RUN_BOT=1 \
  -e TELEGRAM_BOT_TOKEN="$TELEGRAM_BOT_TOKEN" \
  -e TELEGRAM_ADMIN_ID="${TELEGRAM_ADMIN_ID:-8122328795}" \
  -v ms-vps-panel-data:/app/panel_data \
  ms-vps-panel
```

## النشر على Railway

1. ارفع **محتويات مجلد المشروع** إلى جذر المستودع، بما فيها `main.py` و`Dockerfile`؛ لا ترفع ملف ZIP داخل المستودع.
2. احتفظ بـ `railway.json` في الجذر ثم نفّذ Redeploy.
3. اضبط المتغيرات: `RUN_BOT=1`، و`TELEGRAM_BOT_TOKEN` (التوكن الجديد)، و`TELEGRAM_ADMIN_ID=8122328795`، و`BASE_PATH=/app/panel_data`، و`PANEL_URL` بعنوان الموقع العام.
4. اربط Volume دائمًا بمسار `/app/panel_data` حتى تبقى بيانات النقاط والحسابات بعد إعادة النشر.
5. شغّل **نسخة واحدة فقط** من الخدمة لتجنب تكرار Telegram polling؛ يمكن إيقاف البوت بـ `RUN_BOT=0` مع بقاء الموقع يعمل.

## ملاحظات أمان

- لا تضع التوكن أو كلمات المرور في الكود أو Git أو الصور العامة.
- مستخدمو البوت لا يستطيعون فتح وظائف الإدارة؛ كل callbacks الإدارية تقبل المالك وحده، حتى الأزرار الإدارية القديمة.
- كلمات مرور حسابات الموقع لا تُحفظ نصاً مكشوفاً. بيانات النقاط تُخصم داخل معاملة SQLite لتفادي الإنفاق المزدوج عند الطلبات المتزامنة.
